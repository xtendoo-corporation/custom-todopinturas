Todopintura POS Custom Price
=============================

Este módulo permite definir precio personalizado al escanear productos en el Punto de Venta.

Características:
- Campo en categoría de producto para marcar si requiere precio personalizado
- Popup automático al escanear productos de esas categorías
- Aplicación automática de descuentos de lista de precios del cliente
- Integración completa con Odoo 19 POS

Instalación:
1. Instalar el módulo desde Aplicaciones
2. Ir a Inventario > Configuración > Categorías de Productos
3. Marcar "Requiere Precio Personalizado en POS" en las categorías deseadas

Uso:
1. Al escanear un producto de una categoría marcada, aparecerá un popup
2. Introducir el precio personalizado
3. El sistema aplicará automáticamente cualquier descuento de la lista de precios del cliente
4. El producto se añadirá al pedido con el precio y descuento aplicados
